# VerifAI

VerifAI is an intelligent verification and evaluation system.

## Project Structure

```
VerifAI/
├── frontend/     # Web application and user interface
├── backend/      # Core API services and backend logic
├── database/     # Database schemas, migrations, and seeds
├── extension/    # Browser extension
├── mcp/          # Model Context Protocol (MCP) integrations
├── benchmark/    # Benchmarks, evaluation datasets, and test suites
├── docs/         # Documentation and architectural guides
├── scripts/      # Automation, setup, and utility scripts
└── .github/      # GitHub Actions workflows and configuration
```
